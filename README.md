# NTU Map Visualization

# First time

- To start development, run this command at the root folder of this project.
```bash
npm install
```

# How to use

- Run website in dev mode
```bash
npm run dev
```

- Preview website
```bash
npm run preview
```

- Build the website
```bash
npm run build
```

# Where to put files

- `/src`
To put .js, .css, etc.

- `/src/assets/`
To put pictures, static data, etc.

- `/public`
To put icons, etc.
